# My configuration

In this repository is how i configure my computer. Feel free to clone it and make it your own.

## Installation

Before installing, ensure you have git installed and, if you have a mac, [homebrew](https://brew.sh) too.

```shell
[ -d "$HOME/config" ] || git clone https://github.com/mullerjoel/config.git "$HOME/config"; bash "$HOME/config/install.sh"
```
